Scope in JavaScript

📌 What is Scope?

Scope determines the accessibility/visibility of variables in different parts of your code. It defines where variables and functions can be accessed.

📌 Types of Scope

  • Global Scope → Variables declared outside any function (accessible everywhere)
  • Function Scope → Variables declared inside a function (accessible only within that function)
  • Block Scope → Variables declared with let/const inside {} (accessible only within that block)

📌 Variable Declaration & Scope

  • var → Function-scoped (ignores block scopes like if, for)
  • let & const → Block-scoped (respects {} blocks)

📌 Scope Chain

When a variable is used, JavaScript looks for it in the current scope. If not found, it looks in outer/parent scopes (up the chain) until reaching global scope.

📌 Example Flow

const username = 'Anurag'  // Global scope

function add() {
  const username = 'Akash'  // Local scope (shadows global)
  console.log(username)      // 'Akash' - uses local
}

console.log(username)        // 'Anurag' - uses global
