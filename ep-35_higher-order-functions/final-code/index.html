Higher Order Functions in JavaScript

📌 What are Higher Order Functions?

A Higher Order Function is a function that does at least one of the following:

  • Takes one or more functions as arguments (callbacks)
  • Returns a function as its result

📌 What are Callback Functions?

A Callback Function is a function that is passed as an argument to another function and is executed inside that function.

📌 Why Use Higher Order Functions?

  • Code reusability and modularity
  • Abstraction (hide complex implementation)
  • Functional programming paradigm
  • Async operations (event handlers, setTimeout, API calls)

📌 Built-in Higher Order Functions

  • map() → transforms each array element
  • filter() → filters array based on condition
  • reduce() → reduces array to single value
  • forEach() → executes function for each element
  • setTimeout() → executes after delay
  • addEventListener() → handles events

📌 Example Flow

// Higher Order Function
function operate(num, callback) {
  return callback(num);
}

// Callback Function
function double(x) {
  return x * 2;
}

operate(5, double);  // Returns 10
