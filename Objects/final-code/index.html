📚 Functions in JavaScript - Complete Guide

📌 What is a Function?

A function is a reusable block of code that performs a specific task. It's like a machine: you give it input (parameters), it processes, and returns output.

📌 Why Use Functions?

  • Reusability → Write once, use many times
  • Modularity → Break complex problems into smaller pieces
  • Maintainability → Fix bugs in one place
  • Abstraction → Hide complex logic

📌 Types of Functions in JavaScript

  1. Function Declaration (Named Function)
  2. Function Expression (Anonymous Function)
  3. Arrow Function (ES6+)
  4. IIFE (Immediately Invoked Function Expression)
  5. Constructor Function
  6. Generator Function
  7. Async Function
  8. Callback Function
  9. Higher Order Function
  10. Recursive Function

📌 Function Components

function functionName(parameters) {
    // Function body
    return value;  // Optional
}
  • function → keyword
  • functionName → identifier
  • parameters → inputs (optional)
  • function body → code to execute
  • return → output (optional, returns undefined if omitted)

📌 How to See Output?

👉 Open Console (Inspect → Console)
