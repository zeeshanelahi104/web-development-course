📚 Objects in JavaScript - Part 1: Basics & Creation

📌 What is an Object?

An object is a collection of key-value pairs (properties) where each property has a name and a value.

📌 Topics Covered

  • What are objects and why use them
  • Different ways to create objects
  • Accessing and modifying properties
  • Adding and deleting properties
  • Object properties and methods
💡 Key Concept: Objects represent real-world entities with characteristics (properties) and behaviors (methods).

📌 Creating Objects

// Object literal (preferred)
const person = {
    name: 'John',
    age: 30,
    city: 'New York'
};

// Constructor
const car = new Object();
car.brand = 'Toyota';

// Object.create()
const animal = Object.create(prototype);
