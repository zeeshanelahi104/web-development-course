📋 DOM-CRUD App: Code Execution Sequence

Understanding how JavaScript runs your code - Step by Step

🌐 PHASE 1: HTML Parsing & DOM Construction 1
📖 What happens: Browser reads HTML file line by line and builds the DOM tree. 
1. Browser downloads index.html
2. Browser starts parsing from top to bottom
3. Creates DOM elements: header, form-section, table-section
4. Encounters <link rel="stylesheet" href="style.css">
   → Downloads and applies CSS
5. Encounters <script src="script.js">
   → Pauses HTML parsing, downloads script.js
🔍 Browser Console Output:

🎨 Applying CSS styles...

📦 PHASE 2: Script Loading & Hoisting 2
📖 What happens: JavaScript engine loads script.js and performs hoisting (memory allocation). 
// JavaScript engine scans script.js (Creation Phase)

// STEP 1: Allocates memory for variables

// STEP 2: Stores function declarations in memory
function loadFromLocalStorage() { ... }
function saveToLocalStorage() { ... }

🌍 Global Execution Context (Created)
📦 Variables: students[], currentEditId (allocated)

💾 PHASE 4: LocalStorage Data Load 4
📖 What happens: loadFromLocalStorage() reads data from browser storage. 
function loadFromLocalStorage() {
    // 1. Read from localStorage
    const storedStudents = localStorage.getItem('students');
    
    // 2. Parse JSON to JavaScript array
    if (storedStudents) {
        students = JSON.parse(storedStudents);
    } else {
        students = [];  // Empty array if no data
    }
    
    // 3. Update UI
    renderTable();      // ← Another function call
    updateStats();      // ← Another function call
}
💡 Key Point: LocalStorage is synchronous! The code waits for data to load.
📊 PHASE 5: Table Rendering 5
📖 What happens: renderTable() uses innerHTML to display student data. 
function renderTable() {
    // 1. Clear existing content
    studentTableBody.innerHTML = '';
    
    // 2. Loop through students array
    students.forEach((student, index) => {
        // 3. Create HTML string
        const row = document.createElement('tr');
        row.innerHTML = `
            <td>${student.id}</td>
            <td>${student.fullName}</td>
            <td>${student.age}</td>
            <td>${student.email}</td>
            <td>${student.course}</td>
            <td>
                <button onclick="editStudent(${student.id})">Edit</button>
                <button onclick="deleteStudent(${student.id})">Delete</button>
            </td>
        `;
        // 4. Append to DOM
        studentTableBody.appendChild(row);
    });
}

✏️ PHASE 7: User Action - Add Student 7
📖 What happens: User fills form and clicks "Save Student" button. 
// 1. Click event fires
// 2. Event loop picks up the callback
// 3. handleSubmit() is called

function handleSubmit(event) {
    event.preventDefault();  // Stop page reload
    
    const formData = {
        fullName: fullName.value,
        age: age.value,
        email: email.value,
        course: course.value
    };
    
    if (currentEditId) {
        updateStudent(currentEditId, formData);
    } else {
        addStudent(formData);  // ← New student added
    }
}

💾 PHASE 8: Save to LocalStorage 8
📖 What happens: Data is saved to browser storage. 
function saveToLocalStorage() {
    // Convert JavaScript array to JSON string
    const jsonData = JSON.stringify(students);
    
    // Save to localStorage
    localStorage.setItem('students', jsonData);
    
    console.log('Data saved!', students.length, 'students');
}
💡 Key Point: localStorage.setItem() is synchronous - code waits for it to complete!
