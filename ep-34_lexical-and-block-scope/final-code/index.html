Lexical Scope and Block Scope

📌 What is Lexical Scope?

Lexical scope (also called static scope) means that a function's scope is determined by where it is written in the code, not where it is called. Inner functions have access to variables from their outer/parent functions.

📌 What is Block Scope?

Block scope is created whenever you use curly braces { } (if statements, loops, etc.). Variables declared with let and const are block-scoped, meaning they are only accessible within that specific block.

📌 Key Differences

  • var → NOT block-scoped (ignores if/for blocks)
  • let & const → block-scoped (only accessible inside {})
  • Lexical Scope → Inner functions can access outer function variables

📌 Lexical Scope Chain Example

function outer() {
  const outerVar = "outer";
  
  function inner() {
    const innerVar = "inner";
    console.log(outerVar);  // ✅ Can access outer variable
  }
  
  inner();
}
// Lexical scope: inner() can see outer()'s variables

📌 Block Scope Example

if(true) {
  let blockScoped = "only in block";
  var functionScoped = "leaks out";
}
console.log(blockScoped);  // ❌ Error!
console.log(functionScoped); // ✅ Works (var leaks)
